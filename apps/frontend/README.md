# Frontend

Thư mục dành cho mã nguồn và cấu hình frontend của Smart E-Mobility Hub. Hiện chưa có mã triển khai frontend trong cấu trúc này.

- Backend nằm tại [`../backend`](../backend).
- Hợp đồng API và hướng dẫn tích hợp: [Student Portal và Operator Portal](../../docs/api/frontend-integration.md).
- Hướng dẫn chạy dự án: [README ở gốc repository](../../README.md).

Khi triển khai frontend, đặt mã nguồn, `package.json`, lockfile và cấu hình của ứng dụng trong thư mục này.
